2. Purpose

Ofimeo is a set of collaborative office applications (word processor, spreadsheet, drawing, diagrams and presentations) that runs entirely in the user's browser. The owner makes the program available as a static website: it has no application server of its own, creates no user accounts and neither hosts nor receives documents, which are stored on each person's device and exchanged directly between the browsers of the people collaborating.
